## 🚀 Featured Projects

### 🔐 YushaCyber — Cybersecurity Learning Platform
A full-featured, self-built platform for learning offensive security, built with **Flask** and **SQLAlchemy**.

- Interactive labs: **CTF engine**, **network simulator**, **digital-forensics track**, and a **SOC analyst simulator**
- Gamified learning: XP/leveling, roadmaps, quizzes, achievements, certificates, and leaderboards
- Collaborative layer: teams, classrooms, assignments, and discussions
- Engineered to production standards: **220+ passing tests**, security headers, rate limiting, health endpoints, Docker, and CI

`Flask` · `SQLAlchemy` · `pytest` · `Docker` · `CI/CD`

### 🖥️ CyberOps Console — Network Recon Framework
A modular, terminal-based framework for **network reconnaissance and security operations**, built with **Rich** for a clean TUI.

- Pluggable, phase-based architecture across multiple recon and ops modules
- Validated configuration layer and structured logging
- Designed for extensibility — drop in a new module, wire it up, go

`Python` · `Rich` · `Modular architecture`

### 🗺️ cyber_journey — Red Team + AI Security Roadmap
My public learning log: notes, labs, and write-ups from a structured self-directed curriculum.

- Linux, networking, and reconnaissance fundamentals
- Web exploitation — OWASP Top 10, SQLi, XSS, IDOR (PortSwigger / Juice Shop)
- Adversarial ML and LLM security fundamentals
